# RuVacant

An application Rutgers students can use to find empty classrooms within Rutgers University.

---

### Description

The system is made of multiple parts, with a backend system and a frontend system. The backend is composed of a syncing component and an api component. The clients will retrieve data from the api, which will be displayed to the user. Frontend clients will be android and iOS phones.

The full design of the system can be found here: [RuVacant Design Doc](https://docs.google.com/document/d/1rCOOc2DVH5QvLVOohMzPMH5gbPnzUhaa5B8GALFDH78/edit?usp=sharing).

This document includes all designs, both backend and front end, organized into Google Docs Tabs.
